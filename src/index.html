Model- and hardware-specific inference

Inference fitted to the model and the hardware

General-purpose engines are built to run every model on every GPU. Our projects each take one family of models and one device, and change the model, its memory, and its decoding together to fit them.

Quick start

Pick your device and model, then run the command. Sharar, the first MSI engine, runs on the NVIDIA DGX Spark.

  • Needs DGX OS, NVIDIA driver 580 or newer, and the CUDA 13 toolkit.
  • uv installs Python 3.12 and the pinned PyTorch.
  • The first serve downloads the model and builds the GB10 kernels once.
  • See each model's speed and size.
