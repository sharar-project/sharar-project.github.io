Sharar: fast local inference for AI agents

Sharar is an inference engine for the NVIDIA DGX Spark. It runs Qwen and Nemotron models of up to 125B parameters for many agents at once, behind OpenAI- and Anthropic-compatible APIs.

Built for unified memory

On a DGX Spark, the model and every agent's history share one memory. Sharar is designed around that.

Fewer bytes per token

Model surgery

3-bit weights, INT8 recurrent state, and a 2-bit draft head.

How it works → No recomputation between turns

SSD session cache

Every agent's state survives across turns, on the SSD when GPU memory is full.

How it works → More tokens per weight read

Get started

One DGX Spark with DGX OS, driver 580 or newer, and uv.

  1. Clone and sync. uv installs the pinned CUDA 13 PyTorch and FlashInfer, about 7 GB.
  2. Serve a model. The first run downloads it and builds the GB10 kernels.
  3. Use it. Chat in the terminal, or launch a coding agent on it.
# the repository opens with the paper
git clone https://github.com/abdelfattah-lab/sharar && cd sharar
uv sync
uv run sharar serve nemotron     # Nemotron 3.5 Super on :30005

# in another terminal
uv run sharar chat
uv run sharar launch claude
