Model- and hardware-specific inference

One model, one device, one engine built for both

General-purpose engines leave speed on the table on any single device. We build inference engines that specialize to one model family and one piece of hardware, changing the model, its memory, and its decoding together.

See the projects Read the blog

The approach

Start from what the device does well and badly, then edit everything above it to match.

Fit the model to the hardware

Change weight formats, state precision, and the drafter so each token reads fewer bytes on this device.

Use the whole memory hierarchy

Plan GPU memory, host memory, and SSD as one budget, and keep work that will be needed again.

Decode for the workload

Size speculation and batching to the device's real costs and to how agents actually call the model.
